# Research

Long-form source analysis that outlives a single task.

Only two things belong here: analysis that gets **cited by section** across
many tasks, and analysis whose corrections should arrive as reviewed diffs.
Everything else — task detail, findings, decisions — belongs on its issue.

[`platform-baseline-inventory.md`](./platform-baseline-inventory.md) is the map
of what Belimbing owns, what Bilimbi has, and what remains. Read it before
claiming a port. It has been corrected twice under review; if you find it
wrong, correct it in a PR rather than working around it.
