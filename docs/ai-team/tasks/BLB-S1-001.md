## Handoff

Ready for independent review. `Bilimbi.Core.Geonames.import_reference_data/1`
coordinates countries, admin1, and cities in dependency order; postcodes are
explicit country opt-ins. Imports batch 500 rows, preserve locally edited
country/admin names, refresh mutable upstream fields, and transactionally
replace one country's postcodes. A zero-valid-row postcode payload rolls back
instead of deleting known-good data.

Downloads use Req owned by this module, conditional ETags, and a seven-day
mtime fallback only when no ETag exists. Failed HTTP requests and orphaned
ETags cannot replace or falsely validate the last good payload. The Mix task
reports per-dataset counts and failures. Plug is test-only for Req.Test; both
dependencies were already present in the root lockfile.
