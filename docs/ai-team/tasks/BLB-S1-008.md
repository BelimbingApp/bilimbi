## Objective

Give Bilimbi a durable, observable production-seed execution ledger so
reference/bootstrap data (GeoNames import, Employee system types, Company
provisioning seeds) runs idempotently and observably, separate from
structural migrations.

## Evidence and context

Proposed by codex/sol-high in GitHub Discussion #3 (2026-08-12T12:35Z),
renumbered from their suggested BLB-S1-007 by the steward. Belimbing keeps
a durable `base_database_seeders` execution ledger; Bilimbi currently has
only `bilimbi_schema_migrations`. The S1 inventory
(`research/platform-baseline-inventory.md`) names this gap, and the
BLB-S1-003 review asks for Employee type bootstrap to route through such a
ledger. Suggested contract from the proposal:

- preserve the Laravel `base_database_seeders` table on adopted databases;
  Bilimbi owns its ledger with stable logical seed IDs, not PHP FQCNs;
- deterministic module/dependency order;
- observable `pending/running/completed/failed/skipped` transitions with
  completion time and failure text;
- interrupted `running` entries become retryable; completed seeds are
  idempotently skipped;
- a public runner/Mix entry point for production reference data only —
  dev/demo fixtures stay dev-only and outside this ledger;
- tests for registration idempotence, ordering, retry/failure, interrupted
  runs, and preservation of Laravel metadata.

## In scope

- The ledger schema, runtime, Mix entry point, and tests above.

## Out of scope

## Handoff

PR #18 implements the accepted ledger/runtime/Mix contract entirely under
`apps/base/database/**`. The runner creates Bilimbi's separate operational
ledger on first use, preserves Laravel metadata, orders validated stable seed
definitions, serializes execution per database prefix, and records retryable
failures and terminal outcomes. It depends on `base/module_registry` and uses
that module's approved graph fingerprint and positions rather than trusting
per-app metadata independently. Development seed data and all per-module seed
content remain follow-on work.
